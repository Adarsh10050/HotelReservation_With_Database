# Java MySQL Database Connection

This project demonstrates how to connect a **Java application** to a **MySQL database**. It provides a simple interface to interact with a database, perform CRUD (Create, Read, Update, Delete) operations, and manage data effectively.

## Features

- **Database Connectivity**: Establishes a secure connection between a Java application and a MySQL database.
- **CRUD Operations**: Perform CRUD operations (Create, Read, Update, Delete) on database tables.
- **Simple UI**: A console-based interface to interact with the database operations.
- **Exception Handling**: Proper error handling to ensure smooth operation and debugging.

## Technologies Used

- **Java**: The primary language for developing the application.
- **MySQL**: The relational database system for storing and managing data.
- **JDBC (Java Database Connectivity)**: To establish a connection between Java and MySQL
